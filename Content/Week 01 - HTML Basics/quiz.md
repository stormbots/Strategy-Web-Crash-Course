# Quiz

1. What file name does a browser look for as the starting point when loading a website? (Don't forget to include the file extension)
   <details>
   <summary>Answer</summary>

   index.html

   </details>

2. Which html tag contains links to external files such as css files?
   <details>
   <summary>Answer</summary>

   head

   </details>

3. Which tag is missing?

   <!-- prettier-ignore -->
   ```html
   <nav class="sidebar-navigation">
     <div class="user-profile-section">
       <img src="avatar.png" class="profile-pic" alt="User" />
       <div class="user-details">
         <p class="username">JaneDoe99
       </div>
     </div>
     <button class="logout-btn">Log Out</button>
   </nav>
   ```

   <details>
   <summary>Answer</summary>

   p

   </details>

4. Who is the parent of `<ul>`?

   ```html
   <div class="dashboard-widget">
     <section>
       <header>
         <h3>System Status</h3>
       </header>
       <ul class="status-list">
         <li>All servers operational</li>
       </ul>
     </section>
   </div>
   ```

   <details>
   <summary>Answer</summary>

   section

   </details>

5. What does the o stand for in `<ol>`?
   <details>
   <summary>Answer</summary>

   ordered

   </details>

6. What is the space outside of an element's border called?
   <details>
   <summary>Answer</summary>

   margin

   </details>

7. What is the space inside of an element's border called?
   <details>
   <summary>Answer</summary>

   padding

   </details>

8. What does px stand for?
   <details>
   <summary>Answer</summary>

   pixels

   </details>
