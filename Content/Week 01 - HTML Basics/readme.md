## Introduction to Codium

- Open folders through the terminal using `codium .`.

- If warning is present, trust the folder to enable all features.

- Practice creating, renaming, and deleting folders and files.

- Dot on open file indicates unsaved content. Save using `CTRL S`.

- Zoom in and out using `CTRL +` and `CTRL -`.

## Introduction to HTML

- All websites need a main index.html file

- Everything is written using tags

- The basic structure of an html page includes a head and a body. Links to external files (such as css files) goes in the head. The actual html elements that appear on a website go in the body.

- Many HTML elements can contain child elements. Multiple layers of children can exist within an parent.

- Use inspect element on the Google home page to see tags and structure including various layers of elements

- Check out a list of semantic elements in W3 schools. You can reference this list to see if a specific tag in html exists before using a generic tag like `div`.

- Lets get started with a basic website containing a header, nav, main, and footer.
