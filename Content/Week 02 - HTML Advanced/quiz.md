# Quiz

1. What do you call a rough sketch of a web page?
   <details>
   <summary>Answer</summary>

   wireframe

   </details>

2. What kind of query is used to change how a web page looks based on the screen width?
   <details>
   <summary>Answer</summary>

   media

   </details>

3. What should min-height be set to in order to ensure an html page takes up at least the height of the screen?
   <details>
   <summary>Answer</summary>

   100dvh

   </details>

4. Which CSS Layout system is one dimensional?
   <details>
   <summary>Answer</summary>

   flexbox

   </details>

5. Which CSS Layout system is two dimensional?
   <details>
   <summary>Answer</summary>

   grid

   </details>

6. If I'm creating a webpage where I have a section vertically divided into 3 equal parts, what should grid-template-columns be set to?
   <details>
   <summary>Answer</summary>

   1fr 1fr 1fr

   </details>

7. If I'm creating a webpage with a header and footer that should each be 100 pixels in height as well as a main section in-between, what should grid-template-rows be set to?
   <details>
   <summary>Answer</summary>

   100px 1fr 100px

   </details>

8. If I have a navigation bar filled with links and I want them equally spaced out, should I use flexbox or grid to accomplish this?
   <details>
   <summary>Answer</summary>

   flexbox

   </details>

9. If I want to use grid, should I put "display: grid;" on the children or the parent?
   <details>
   <summary>Answer</summary>

   parent

   </details>

10. Will this code work as expected, yes or no?

    HTML Snippet

    ```html
    <div>
      <div class="child">left child</div>
    ```

    ```css
    .child {

    }
    ```
