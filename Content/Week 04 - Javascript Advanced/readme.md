# Class Notes

## Functions

- Functions allow for code to be easily reused. They can function diffrently based on the inputs reeieved.

- A function can recieve parameters and return data, but doesn't neccessarily have to have an input or output.

- Functions will work when called and can be called multiple times, but no output will be shown unless you explicitly log the output.

- A function can recieve multiple parameters, but can only return one value. Although this value can be an array or object containing multiple values.

## Arrays

- A specific value can be accessed using its index position. It can then be modified by simply reassigning the value.

- Data can be added to arrays using the push method. 

## Objects

- Objects contain key value pairs. A specific value can be accessed by using the key name in either bracket or dot notation.

- Data can be modified or deleted by using the keyName

## Loops

- While loops will continue to work while a specific condition is being met. 

- Either a regular for loop or a for in loop can be used to loop through the values in an array.

- A for in loop can be used to loop through the key value pairs in an object.

- Data can be modified or added into an array or object while looping.
